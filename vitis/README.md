# vitis 目录说明

这里是 Xilinx Vitis 工作区副本，包含当前板端应用、平台工程、FSBL/BSP、硬件导入文件和 IDE 元数据。

## 主要内容

- `0806_/src/`：当前板端裸机应用源码，包含 AD7606 DMA、TCP 数据流、RS485/Modbus、外部脉冲统计、脉冲输出和校准逻辑。
- `0806_1/`、`0804_1/`：由 XSA 生成的平台工程，保存硬件描述、BSP、FSBL 和导出资源。
- `0806__system/`、`0804_1__system/`：系统工程和启动镜像相关输出。
- `RemoteSystemsTempFiles/`：Vitis 自动生成的临时远程系统文件。
- `.metadata/`：IDE 元数据、索引和日志。
- `IDE.log`：Vitis IDE 日志。

## 开发入口

如果要改板端业务逻辑，优先进入 `0806_/src/`。当前较完整的实现路径主要是：

- `main.c`：采集主循环、流速换算、测量页回写、校准应用和手动系数应用。
- `rs485_modbus.c/.h`：Modbus 寄存器映射。
- `external_flow.c/.h`：外部脉冲统计与标准流量。
- `flow_pulse.c/.h`：本机脉冲输出和脉冲参数设置。
- `app_config.h`：算法与硬件常量。

## 当前寄存器口径

- `4WUB0001-0004`：测量页数据，板端发送原始整数，屏幕侧按 `0.001` 显示。
- `4WUB0005`：测量页清零命令。
- `4WUB0116-0117`：当前生效 K/B。
- `4WUB0150-0152`：脉冲体积(mL)、脉冲个数、脉宽(ms)。
- `4WUB0160-0162`：手动输入 K/B 与应用命令。

## 备注

`ws/` 和 `vitis/` 有较大重叠。若要判断当前最终源码，以 `ws/0806_/src` 的内容为准。
