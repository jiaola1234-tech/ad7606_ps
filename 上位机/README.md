# 上位机 目录说明

本目录保存流量计 PC 上位机软件，包括源码版和打包后的独立运行版。

## 主要内容

- `源码/`：Python/PySide6 上位机源码、MATLAB 算法文件、测试脚本、模拟发送器和界面截图。
- `打包后独立可用及其所需依赖/`：已打包的 `SonarFlowMeterHost.exe`，可在 Windows 64 位系统上直接运行。

## 功能概览

上位机用于通过网络接收下位机采样数据，显示 8 路实时曲线，调用或降级模拟 MATLAB 流速算法，展示当前流速/流量信息，并支持 CSV 导出。

## 使用建议

- 只运行软件：进入 `打包后独立可用及其所需依赖/`，双击 `SonarFlowMeterHost.exe`。
- 修改或调试源码：进入 `源码/flowmeter_host/`，按其中 README 安装依赖并运行 `python main.py`。
- 更换 MATLAB 算法：替换或在界面中选择 `.m` 文件，当前目录中保留了 `ana96.m`。
