源码目录说明

目录结构：
  ana96.m                 MATLAB 算法源码
  flowmeter_host\app      上位机程序源码
  flowmeter_host\tests    测试代码
  flowmeter_host\tools    模拟数据发送工具
  flowmeter_host\界面截图  开发和界面校验截图
  flowmeter_host\.run_venv 本机即用 Python 3.11 开发环境

开发依赖：
  见 flowmeter_host\requirements.txt。

在当前电脑直接运行源码：
  1. cd flowmeter_host
  2. 双击 运行源码.bat

在其他电脑重建环境：
  1. cd flowmeter_host
  2. python -m venv .venv
  3. .\.venv\Scripts\activate
  4. python -m pip install -r requirements.txt
  5. python main.py
