# 屏幕目录说明

这里保存 MCGSPro 触摸屏工程文件，用来配置现场页面、变量绑定和与板端 RS485/Modbus 的交互。

## 主要内容

- `流量计 MCP`：当前主工程，包含测量页、校准页、手动系数页和脉冲参数页。
- `流量计 MCP.bak`：工程备份。
- `流量计 MCP.user.bak`：用户级备份。
- `流量计 MCP_McgsPro 3.3.2.5166_0.old`：旧版本工程。
- `流量计 MCP.ldb`：工程锁定数据库辅助文件。

## 主要页面

- 测量页：显示原始流速、校准流速、瞬时流量、累计流量和清零按钮。
- 校准页：设置目标点数、采集时间、开始/结束/拟合/清零。
- 手动系数页：输入手动 K/B，并通过应用命令让板端采用新系数。
- 脉冲参数页：设置脉冲体积(mL)、脉冲个数和高电平脉宽(μs)。

## 当前变量口径

- `4WUB0001-0004`：测量页数据，板端发整数，屏幕侧按 `0.001 * X` 显示。
- `4WUB0005`：测量页清零命令。
- `4WUB0116`：当前生效 K。
- `4WUB0117`：当前生效 B。
- `4WUB0160`：手动 K 原始值。
- `4WUB0161`：手动 B 原始值。
- `4WUB0162`：应用命令。
- `4WUB0150`：脉冲体积，单位 mL。
- `4WUB0151`：脉冲个数。
- `4WUB0152`：高电平脉宽，单位 μs；例如填写 `20` 表示约 20 μs。

## 手动输入约定

手动输入框建议直接写原始整数值，由板端做统一换算：

- `K真实值 = 0160 / 1000`
- `B真实值 = 0161 / 1000`

这样可以把“屏幕显示”和“屏幕输入”拆开，避免同一个寄存器同时承担两个方向的数据处理。

## 说明

屏幕工程中的变量地址必须和板端 `rs485_modbus.c/.h` 的寄存器表保持一致。寄存器调整后，屏幕工程和说明文档要一起更新。
