# ws 目录说明

这里是另一套 Xilinx Vitis/SDK 工作区，保存当前板端业务源码和系统工程。

## 目录内容

- `0806/`：平台工程，包含 XSA 导入后的硬件描述、BSP、FSBL 和导出资源。
- `0806_/src/`：当前板端业务源码，流量计算、RS485/Modbus、脉冲输出、外部脉冲统计和校准逻辑都在这里。
- `0806__system/`：系统工程与 SD 卡启动文件生成相关内容。
- `.metadata/`：IDE 元数据和日志。
- `RemoteSystemsTempFiles/`：Vitis/SDK 自动生成的临时远程系统文件。

## `0806_/src/` 模块概览

- `main.c`：程序入口、硬件初始化、主循环、测量计算、校准应用和结果回写。
- `ad7606_dma.c/.h`：AD7606 采样与 DMA 传输。
- `tcp_stream.c/.h`：TCP 原始数据流。
- `rs485_modbus.c/.h`：RS485/Modbus 寄存器映射与读写。
- `external_flow.c/.h`：外部脉冲统计与标准流量计算。
- `flow_pulse.c/.h`：本机脉冲输出与脉冲参数控制。
- `app_config.h`：采样率、通道数、管径和算法常量。

## 当前寄存器约定

- `4WUB0001-0004`：测量页，原始流速、校准流速、瞬时流量、累计流量。
- `4WUB0005`：测量页清零命令。
- `4WUB0100-0106`：校准采集控制页。
- `4WUB0110-0118`：校准状态与当前生效 K/B。
- `4WUB0120-0139`：原始曲线与校准曲线点。
- `4WUB0140-0145`：增益挡位状态与挡位命令。
- `4WUB0150-0152`：脉冲体积(mL)、脉冲个数、高电平脉宽(μs)。
- `4WUB0160-0162`：手动 K/B 输入与应用命令。

## 说明

板端源码修改优先在 `0806_/src/` 内完成。寄存器映射调整后，要同步更新屏幕工程和说明文件，避免屏幕变量、板端寄存器和调试断点的口径不一致。
